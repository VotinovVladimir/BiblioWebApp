# Курсовой проект: Интернет-приложение «Библиотека»

## Формат сдачи
- Пояснительная записка (10 разделов по ТЗ)
- Работающее web-приложение (запуск локально, http://127.0.0.1:5000)
- Скриншоты визуальных форм в ПЗ
- Листинг программы

## Стек
Python 3.11 + Flask 3 + Flask-SQLAlchemy + SQLite + Jinja2 + Bootstrap 5
